# Last-Mile Delivery Tracker

A full-stack delivery management platform for managing customer orders, delivery agents, shipment tracking, pricing, and notifications.

## Features

- Customer registration and login
- Customer dashboard
- Delivery order creation
- Automatic delivery charge calculation
- Order tracking
- Delivery notifications
- Agent authentication
- Agent availability management
- Agent location management
- Automatic nearest-agent assignment
- Delivery status management
- Admin agent management

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS / CSS
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Nodemailer
